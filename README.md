# moetran-poprako-support

moetran-poprako-support is the supporter server of [moetran-poprako](https://github.com/ATOMLubover/moetran-poprako).

## Quick Start

### Prerequisites

- Rust toolchain + cargo

### Local development

```powershell
cargo run
```
